# Demonstration and submission

## Core story
Start at real terrain for a documented wildfire. Show verified camera viewpoints, click playable evidence, ask 'Where did smoke first appear, and can another camera corroborate it?' Show the agent searching and inspecting evidence, selecting a second viewpoint when justified, and producing clickable timestamped findings. If geometry supports it, display candidate region and uncertainty; otherwise explicitly show insufficient calibration.

The confirmed complete-demo target is real 3D terrain and at least two independent verified Holy Fire camera views in the Next.js/React/Cesium application. A single video, synthetic data or missing terrain is an interim development state, not completion. Geographic localization remains conditional on calibration.

## Honest demo variants
**Full live:** wildfire footage indexed in permitted VAST environment and Cosmos reasoning verified. **Hybrid:** authorized local wildfire clips + live Cosmos, but VAST search only on its actually indexed corpus. **Fixture:** useful UI/investigation demonstration, conspicuously labelled synthetic. Never claim one variant is another.

## Pre-demo checks
Playable assets and timestamp seek; Cesium token/terrain; API connectivity; source provenance and rights; no secrets in UI; agent actions and citations; fallback on unavailable model; documented scientific limitations.

## Submission
Follow current event organizer requirements and actual deadline rather than relying on older copied schedules. Prepare public-safe repository, demo recording, concise technology explanation, and team information. Do not include credentials, unauthorized footage, or invented integration claims.
